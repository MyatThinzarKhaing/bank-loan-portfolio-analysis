# Bank Loan Portfolio Analysis

## Project Overview

A data analytics project focused on analyzing bank loan applications, borrower characteristics, loan performance, and portfolio KPIs using SQL, Python, and Power BI.

The analysis uses a bank loan dataset containing approximately 38K loan records.

## Tools

* Microsoft SQL Server
* Python (Pandas, Matplotlib, Seaborn)
* Power BI
* Excel

## Key Analysis

The project analyzes:

* Loan application volume
* Funded loan amounts
* Total payments received
* Average interest rate
* Average debt-to-income ratio (DTI)
* Good vs. bad loan performance
* Loan purpose
* Loan grade
* Employment length
* Home ownership
* Monthly loan trends

## SQL Analysis

SQL was used to calculate and validate key portfolio metrics, including:

* Total loan applications
* Monthly application trends
* Total funded amount
* Total amount received
* Average interest rate
* Average DTI
* Good loan percentage
* Bad loan percentage

I also added additional analysis of loan performance by loan purpose, loan grade, and loan status.

## Python Analysis

Python/Pandas was used for data inspection, preprocessing, and exploratory analysis.

Visualizations were used to examine:

* Monthly loan trends
* Loan purpose distribution
* Interest rates
* DTI
* Loan status
* Borrower characteristics

## Power BI Dashboard

The Power BI dashboard provides interactive analysis of:

* Portfolio KPIs
* Loan status
* Monthly trends
* Loan purpose
* Loan term
* Employment length
* Home ownership
* Geographic distribution

## Key Findings

The analysis was used to identify differences in loan volume and performance across loan status, purpose, borrower characteristics, and financial indicators.
